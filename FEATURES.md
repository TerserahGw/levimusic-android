- **Pencarian musik online** berdasarkan judul atau penyanyi dari katalog publik Audius melalui menu mod.
- **Streaming rekaman audio asli** dengan Android MediaPlayer, tanpa impor MP3 lokal satu per satu.
- **Kontrol musik dalam game:** Play/Pause, Stop, Next, Previous, serta volume.
- **Navigasi hasil pencarian:** memilih hasil berikutnya atau sebelumnya.
- **HUD musik** dan tombol kontrol melalui API Mod Menu LeviLauncher Android.
- **Lirik tersinkronisasi opsional** dari LRCLIB jika data lirik cocok dan tersedia.
- **Minecraft Bedrock asli**, mod native Android ARM64 (`.so`), bukan Java Edition.

> Status fitur: sudah diimplementasikan dalam source, **belum terverifikasi melalui uji runtime pada Minecraft/LeviLauncher Android**.

> **Compatibility note:** v0.1.0 was reported to hang at a black screen on startup. Subsequent versions target the Preloader ABI embedded in LeviLauncher Android v1.7.1, but on-device compatibility is still unverified. Mod runtime may vary by launcher/game version.
