# LeviMusic - Aurelis Online v1.5.0 stable

A client-side music player for Minecraft Bedrock on LeviLauncher Android ARM64. World-space 3D lyrics are visible only to the local player.

## Minecraft compatibility

- **3D world lyrics:** Minecraft 1.26.52, 1.26.60, and 1.26.62.1 on matching ARM64 Build IDs and renderer signatures.
- **Minecraft 1.26.66.1:** Core music may run if the loader accepts the mod. 3D rendering has not been verified for this version.

## Changes since v1.4.6 beta

- Adopted the supplied 3D lyric layout as the default for new installs while keeping existing user settings. The in-game settings menu now has four touch-friendly pages.
- Added in-game playlist creation, adding songs from search results, and removing songs from a playlist. Standalone stores playlists locally; Bridge migrates existing playlists to an atomic file and retains the earlier copy.
- Improved settings and Standalone playlist writes with temporary files and backups.

## Choose a download

- **Full mode:** install `LeviMusic-1.5.0-arm64-v8a.levipack` and the matching `LeviMusic-Bridge-1.5.0.apk`.
- **Standalone:** install `LeviMusic-Standalone-1.5.0-arm64-v8a.levipack` without the Bridge APK. It still requires internet access to Aurelis Symphony.

Enable only one LeviPack variant at a time.
