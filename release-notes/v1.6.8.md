# LeviMusic - Aurelis Online v1.6.8 stable

- Immersive Sound and 3D Lyrics Beats are now exclusive to Standard; both controls and their runtime paths have been removed from Standalone.
- Standard now retains environment changes that arrive before playback starts and periodically resynchronizes the active environment with Bridge.
- Room and cave detection covers higher ceilings and irregular walls while holding the enclosed result across short query gaps.
- Cave playback uses stronger multi-tap PCM reflections, stereo cross-reflections, and a longer feedback tail without relying on vendor audio effects.

Standard mode requires the matching v1.6.8 Bridge APK.
